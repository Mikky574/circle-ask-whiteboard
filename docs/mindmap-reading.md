# 导图阅读

在画布标题下方「显示方式」栏选择「导图阅读」，同一张白板会以双侧标题树呈现。样式参考本地 iNaturalist-Plus 思维导图：根节点居中、一级分支淡色分组、细节节点以文字和细线呈现，完整说明留在右侧。

## 阅读与提问

- 点击标题，右侧展示该节点的完整说明、来源和已有细节。图上缩短呈现不截断模型上下文。
- 右侧「下级详解」可阅读已收起子节点的正文，并继续逐层展开。点「查看节点」在同一白板选中、展开路径并定位对应卡片。
- 实现步骤、任务依赖、验收资料、附件和源码片段均来自已有记录。已保存的完整回答、拆分前的原始回答分别标注，保留全部原文，不用摘要替代。没有记录的内容会提示未补充。
- 同一节点的详情会保留已打开的章节、阅读位置和文本选择；点选另一个节点后从新节点正文开始阅读。
- 原有节点 ID、父子关系、提问、追问、拆分、连接、搜索和附件继续使用白板原有实现。
- 点击节点旁的加号或减号，逐级展开或收起。下级计数沿用白板真实关系。
- 局部展开和收起保持点击节点的位置与缩放，左右分支保持方向；「适应整个白板」才重新缩放到总览。
- 「只看主干」收起一级模块下的细节；「全部展开」打开已有节点，不调用模型生成内容。
- 点「查看卡片」回到所选节点的卡片形式，便于阅读图文、编辑和局部圈选。

## 布局与保存

导图根据可见标题的实际尺寸，使用现有双侧树布局计算位置。布局不会根据隐藏正文的长度预留空白。父子线使用同一分支颜色和曲线，连接模式仍保留实际父边与删除连接操作。

卡片坐标与导图阅读坐标分别保存；切回卡片时保留原布局。「快速重排导图分支」只处理选中节点的后代，其他分支、根节点和图钉保持原位，支持撤销。未选节点时重排整张导图。

呈现偏好及阅读坐标在本机按白板保存。主干/全部展开操作修改该白板已有的折叠状态，和原生展开收起一致。数据导出仍以白板内容和关系为准。

## 验证

运行 `node test_mindmap_browser.mjs`，使用独立浏览器与临时模拟服务检查布局、正文、父子关系、模式切换、刷新以及原生问答入口。模型回复使用夹具，不代表已验证真实供应商连接。
