# 导图阅读

在白板顶部选择「导图阅读」，同一张白板会以双侧标题树呈现。样式参考本地 iNaturalist-Plus 思维导图：根节点居中、一级分支淡色分组、细节节点以文字和细线呈现，完整说明留在右侧。

## 阅读与提问

- 点击标题，右侧展示该节点的完整说明、来源和已有细节。模型上下文按原有长度预算组织，包含所属卡片说明和分支背景，不能只用图上的标题代替。
- 说明顶部的「问这张卡」打开提问框；回答继续挂在这张卡下面。选中回答节点后可继续追问。
- 在右侧详情中按住鼠标拖选一句或一段文字，原文会高亮，并出现「问这段」。点它后输入问题再发送；模型同时收到选段、所属卡片说明、父级路径及相关讨论，局部引用不会被当成整卡选择。选段较长时本次引用使用前 600 字。
- 「向下延伸」先让你填写展开方向，再生成下级；「拆成子节点」使用已有拆分工具。不会因为点开入口就自动发送模型请求。
- 「下级详解」能逐层阅读已有子节点，方法、验收、文件和附件均取自真实记录。直接选中其中一张子卡的文字提问，会定位并挂到该子卡下面；跨两张卡片的选文需要分别提问。
- 同一节点的日常状态更新保留阅读位置、展开章节和原生文字选择；换节点、白板或呈现方式时清除选段，避免引用旧内容。
- 原有节点 ID、父子关系、提问、追问、拆分、连接、搜索和附件继续使用白板原有实现。
- 点击节点旁的加号或减号，逐级展开或收起。下级计数沿用白板真实关系。
- 「只看主干」收起一级模块下的细节；「全部展开」打开已有节点，不调用模型生成内容。
- 点「查看卡片」回到所选节点的卡片形式，便于阅读图文、编辑和局部圈选。

## 布局与保存

导图根据可见标题的实际尺寸，使用现有双侧树布局计算位置。布局不会根据隐藏正文的长度预留空白。父子线使用同一分支颜色和曲线，连接模式仍保留实际父边与删除连接操作。

卡片坐标与导图阅读坐标分别保存；切回卡片时保留原布局。「快速重排导图分支」只处理选中节点的后代，其他分支、根节点和图钉保持原位，支持撤销。未选节点时重排整张导图。

呈现偏好及阅读坐标在本机按白板保存。主干/全部展开操作修改该白板已有的折叠状态，和原生展开收起一致。数据导出仍以白板内容和关系为准。

## 验证

运行 `node test_mindmap_browser.mjs`，使用独立浏览器与临时模拟服务检查布局、正文、父子关系、模式切换、刷新、鼠标拖选、引用上下文以及原生问答和下级生成入口。模型回复使用夹具，不代表已验证真实供应商连接。
