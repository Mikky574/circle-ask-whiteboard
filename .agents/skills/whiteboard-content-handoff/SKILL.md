# 将工作成果同步到圈问白板

## 定位白板与证据

1. 用用户给的白板 URL 或项目目录打开**可编辑画布**，核对标题、`board` 参数和项目目录。原生服务默认 8791，WM‑08 整合包默认 8798，用户原白板可能在不同端口。新版服务按板号读取共享的本机数据库，内置浏览器和用户浏览器应看到同一份内容。端口不同的服务须使用同一数据库；旧服务需升级并重新启动，不能仅凭相同板号认定同步成功。
2. 从本轮已完成的工作、用户指定的文件、运行结果中提取要落板的内容。每张卡讲一个主题，写清结论、条件和证据。源码用仓库相对路径及符号，论文用页码、图表或 DOI，验证写实际运行的结果，待验证项保留其状态。
3. 在「搜卡」里用功能、指标名或卡片标题定位相关卡片，展开可能相关的父卡，对照已有正文和同级卡。相同对象的新证据更新原卡。能独立回答的新细节挂在最贴近的已有父卡下。跨分支内容按来源分开，其他分支可引用已有卡号。若多个父卡都合理且用户的目标也无法区分，先给出候选路径并请求选择。

## 用对应入口写入

外部会话已经有确定成稿，且目标是已有结构化白板时，优先使用同目录下的 [whiteboard-service](../whiteboard-service/SKILL.md)：读取板号和根卡，以局部 JSON 提案更新原卡或追加多层下级，通过服务 CAS 保存并读回。不需要为了写入成稿再调用一次模型，也不依赖代理私有浏览器。空白板初始化或需要模型继续生成内容时，使用下面的界面入口。

| 用户要做的事 | 使用白板里的入口 |
| --- | --- |
| 从项目源码建立第一张白板 | 新建空白板，绑定明确的项目目录，选择已配置的 Codex 或 ZCode。点「初始化工程介绍」，生成后检查主干和子卡。 |
| 为报告、论文或已规划的内容建立白板 | 新建空白板，点「写第一张卡片」录入总览。已有确定的章节结构可逐项新建，按父卡到子卡连线。 |
| 修正同一张卡的结论、指标或验收结果 | 右键选「编辑卡片」。以当前正文为底稿，保留仍成立的事实、原卡号、父卡和任务属性。更新内容后点「保存卡片」。 |
| 给现有主题新增已写好的内容 | 点「新建卡片」或右键空白区选「在此新建卡片」，填入标题、正文并保存。进入「连线」模式，先点目标父卡，再点新卡。逐项核对挂接方向。 |
| 由白板里的模型扩写一个主题 | 右键目标父卡选「拆分节点」，填写方向，点「生成下级」。需要多层时使用「多级拆分」，并按问题提示选择范围。该操作由白板根据选区和资料生成新卡。 |
| 用新证据修订整条已选分支 | 右键根卡选「重新生成分支」，只提交这条分支的纠偏意见。该入口会覆盖范围内各节点的文字，包括收起的下级。若用户要求调整分支内部的顺序或结构，才使用「整理分支」。 |
| 从既有白板并行尝试新方案 | 点保存状态旁的「版本 vN · 分支」，选择当前或明确的历史版本，命名后建分支。核对新板号及来源板号、版本，再在新板修改；原板不随分支变动。 |
| 恢复过去的白板内容 | 在版本面板先预览目标快照，再点「恢复」。恢复会新增版本，原有历史继续保留。恢复后重新核对板号、内容和保存状态。 |

外部 Codex 或 ZCode 可通过服务技能写入，或用可操作的浏览器工具执行上表。服务技能第一版只处理已有 `current.items`，不初始化空板、不删除、不重挂已有节点。WM‑08 页面可通过「白板工具」打开编辑表单或连接设置。用右键或明确的按钮操作，避免把「问选中内容」生成的批注误报为正式子卡。已定稿的文字直接录入，需要模型改写时才调用白板中的模型后端。

白板的目录、卡片与批注、关系、布局、项目规则及替换备份统一保存在本机服务，默认文件为 `~/.circle-ask-whiteboard/boards.sqlite3`，`WHITEBOARD_BOARDS_FILE` 可指定其他文件。浏览器仅缓存内容和未同步修改。服务的 `/api/codex` 生成有范围的候选响应，前端校验后通过 `/api/board-store` 提交；模型回答完成不代表已保存。使用服务技能或正常 UI 写入，不直接改 localStorage、SQLite、初始模板或项目清单。只有用户要求修改原型源码时才涉及「允许本次修改代码」。

从旧版升级时，原浏览器第一次打开新版页面才可迁移其中的私有记录。服务已有版本时不自动用旧缓存覆盖。出现恢复副本或版本冲突，先对照两份内容，再合并此次差异；不要清空浏览器存储或强行覆盖版本号。

## 核对与交接

- 提交前再次核对板号、父卡题名和现有正文。若页面提示内容已更新，重新读卡再合并本轮差异。追加前检查同一主题、来源和工作点是否已存在。
- 完成后展开目标分支，等待页面显示「已保存到本机服务」，再刷新核对正文与父卡。可操作独立浏览器上下文时，用同一链接重新读取，确认无需复制浏览器存储也能看到结果。返回实际白板链接、更新或新增的卡号、挂接路径及证据来源。保存失败、仅有本地缓存或模型只返回候选时，准确说明尚未同步，不能报告交付完成。
- 没有权限或无法接入用户浏览器时，交付可粘贴的清单。每项写出操作、目标卡或父卡路径、短标题、正文和证据。准确标明尚未写入。对目标白板和父卡有明确授权并且能实操时，提交并核对后再结束。

## WM‑08 示例

用户说「把刚核实的 13 GHz 64‑QAM 测量补到样片实测下」。先打开 WM‑08，找到「样片实测」并展开。如果已有同一载波、格式和带宽的卡片，原位补上核实的读数和论文页码。如果要新增独立的「调制测试条件」细节卡，把它连到这张实测卡下。「论文贡献」分支保留跨论文比较和工程判断，可引用实测卡，省去重复记录。
