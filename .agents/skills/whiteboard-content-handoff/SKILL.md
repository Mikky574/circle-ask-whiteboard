# 将工作成果同步到圈问白板

## 定位白板与证据

1. 用用户给的白板 URL 或项目目录打开**可编辑画布**，核对标题、`board` 参数和项目目录。原生服务默认 8791，WM‑08 整合包默认 8798，用户原白板可能在不同端口。相同板号换端口或浏览器配置文件时会读到不同的本机记录。
2. 从本轮已完成的工作、用户指定的文件、运行结果中提取要落板的内容。每张卡讲一个主题，写清结论、条件和证据。源码用仓库相对路径及符号，论文用页码、图表或 DOI，验证写实际运行的结果，待验证项保留其状态。
3. 在「搜卡」里用功能、指标名或卡片标题定位相关卡片，展开可能相关的父卡，对照已有正文和同级卡。相同对象的新证据更新原卡。能独立回答的新细节挂在最贴近的已有父卡下。跨分支内容按来源分开，其他分支可引用已有卡号。若多个父卡都合理且用户的目标也无法区分，先给出候选路径并请求选择。

## 用对应入口写入

| 用户要做的事 | 使用白板里的入口 |
| --- | --- |
| 从项目源码建立第一张白板 | 新建空白板，绑定明确的项目目录，选择已配置的 Codex 或 ZCode。点「初始化工程介绍」，生成后检查主干和子卡。 |
| 为报告、论文或已规划的内容建立白板 | 新建空白板，点「写第一张卡片」录入总览。已有确定的章节结构可逐项新建，按父卡到子卡连线。 |
| 修正同一张卡的结论、指标或验收结果 | 右键选「编辑卡片」。以当前正文为底稿，保留仍成立的事实、原卡号、父卡和任务属性。更新内容后点「保存卡片」。 |
| 给现有主题新增已写好的内容 | 点「新建卡片」或右键空白区选「在此新建卡片」，填入标题、正文并保存。进入「连线」模式，先点目标父卡，再点新卡。逐项核对挂接方向。 |
| 由白板里的模型扩写一个主题 | 右键目标父卡选「拆分节点」，填写方向，点「生成下级」。需要多层时使用「多级拆分」，并按问题提示选择范围。该操作由白板根据选区和资料生成新卡。 |
| 用新证据修订整条已选分支 | 右键根卡选「重新生成分支」，只提交这条分支的纠偏意见。该入口会覆盖范围内各节点的文字，包括收起的下级。若用户要求调整分支内部的顺序或结构，才使用「整理分支」。 |

外部 Codex 或 ZCode 可用自身可操作的浏览器工具执行上表。WM‑08 页面可通过「白板工具」打开编辑表单或连接设置。用右键或明确的按钮操作，避免把「问选中内容」生成的批注误报为正式子卡。已定稿的文字直接录入，需要模型改写时才调用白板中的模型后端。

白板通过浏览器保存用户的卡片与批注。服务的 `/api/codex` 生成有范围的候选响应，前端负责校验和提交。用正常 UI 写入，无需自行改 localStorage、初始模板、项目清单或拼装内部接口请求。只有用户要求修改原型源码时才涉及「允许本次修改代码」。

## 核对与交接

- 提交前再次核对板号、父卡题名和现有正文。若页面提示内容已更新，重新读卡再合并本轮差异。追加前检查同一主题、来源和工作点是否已存在。
- 完成后展开目标分支，刷新并核对新增卡或更新后的正文仍在、父卡正确。返回实际白板链接、更新或新增的卡号、挂接路径及证据来源。仅生成草稿或模型返回候选时说明当前状态。
- 没有权限或无法接入用户浏览器时，交付可粘贴的清单。每项写出操作、目标卡或父卡路径、短标题、正文和证据。准确标明尚未写入。对目标白板和父卡有明确授权并且能实操时，提交并核对后再结束。

## WM‑08 示例

用户说「把刚核实的 13 GHz 64‑QAM 测量补到样片实测下」。先打开 WM‑08，找到「样片实测」并展开。如果已有同一载波、格式和带宽的卡片，原位补上核实的读数和论文页码。如果要新增独立的「调制测试条件」细节卡，把它连到这张实测卡下。「论文贡献」分支保留跨论文比较和工程判断，可引用实测卡，省去重复记录。
