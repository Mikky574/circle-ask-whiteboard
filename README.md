# 圈问白板

一个运行在本机浏览器里的白板。可以圈选卡片局部提问、沿批注继续追问、整理主干和分支，也可以拖动卡片或快速重排。

**从首页开始。** 打开或添加一个本机项目，直接进入项目画布。空画布可以先写一张主干卡，也可以从源码生成工程介绍。回顾项目结构或动作时，在项目内切换视图。点 **关闭项目** 回到首页，之后可以打开同一张画布继续写。

按功能查找操作入口、设计目的、当前边界和验收方式，请阅读 [圈问白板功能说明](docs/whiteboard-feature-guide.md)。

## 启动

需要 Python 3.10 或更新版本。在仓库根目录运行。

```powershell
python -B server.py
```

打开 [本地首页](http://127.0.0.1:8791/)。进入画布后，在 **连接设置** 里选择 Codex、ZCode 或 API 直连。CLI 模式需要终端能找到并运行已登录的对应 CLI。模型留空时使用该 CLI 的默认模型。Codex 可填写模型 ID，ZCode 可填写其配置中的 `供应商ID/模型ID`。

Codex 沿用本机 `codex login`。ZCode 沿用本机 CLI 配置和登录，可以按账号地区运行 `zcode login bigmodel` 或 `zcode login zai`。可用模型取决于对应账号和供应商配置。ZCode 不在 `PATH` 时，可以在启动前把环境变量 `WHITEBOARD_ZCODE_EXECUTABLE` 设为 CLI 路径。[ZCode CLI 文档](https://github.com/zai-org/ZCode/tree/main/apps/zcode-cli)

## 操作

- 拖动画布空白处可平移。点进画布后可用方向键移动视野，按住 Shift 可加快。鼠标滚轮或触控板双指滑动可平移，Shift + 滚轮可横移，Ctrl / ⌘ + 滚轮可在指针位置缩放。按住空格拖动或按下鼠标中键拖动，也能从卡片上开始平移。
- **圈选** 模式下可从卡片上开始圈选。从空白处开始圈选多张卡片时，按住 Shift 再拖动。
- 点选卡片或圈选片段，点击 **问 AI** 后输入并发送。智能体判断要回答、重答、延伸分支、补充主干、整理白板还是按请求修改原型源码。
- 画布上的 **搜卡** 可按标题、编号、正文或卡片引用的源码符号定位。搜索会临时展开目标路径，点 **回到总览** 会收回临时展开的路径。整卡提问、整板问答和归档可以读取已保存的折叠卡片。
- Codex/ZCode 修改源码需先确认问题、选区、附件、服务和模型，再勾选 **允许本次修改代码**；这些内容变化或发送后清除。普通解释不会仅凭模型分类获得编辑权限。
- 另一标签页更新同一张白板后，本页会暂停保存并保留未保存内容。请先复制目标、约束、决定或问题草稿，再点 **刷新白板** 读取最新内容；刷新会丢弃本页尚未保存的改动。
- 可以把文件拖进提问框或直接拖到白板，也可以点击 **添加附件**。复制截图后可在提问框按 **Ctrl+V**，截图会进入附件列表。每个文件上限 10 MiB，点击发送时上传。从带附件的批注或模块继续问时，本机会把相关附件一并交给当前服务。实际识读能力取决于文件格式和所选模型。
- 点击白板卡片或批注里的 **附件** 可打开已保存的文件。UTF-8 Markdown 和文本可直接查看，其余格式按文件下载。
- 点 **整理白板**，在弹窗里查看范围并填写本次意见，点 **开始整理** 后提交。意见可以留空。常用意见可在 **整理选项** 设为默认，整理结果支持撤销。没有选中卡片时，**快速重排整个白板** 循环切换紧凑树形、横向展开、双侧展开。选中卡片后，按钮变为 **快速重排选中分支**，只排该模块的全部下级，父卡固定在原位。各分支单独记住排布样式，Shift 多选可以同时重排多个分支。等待整理时也可以重排或撤销。
- 选中一张卡片后，可以点 **拆分模块**，把选中的内容展开成说明卡，或把已有任务拆成下级任务。点 **多级拆分** 可以一次生成至少两级新增卡片，细节挂在对应的上级卡下，默认可逐级展开。也可以在提问里要求一次生成多级说明卡或任务卡。**整理分支** 会根据整理意见更新这张卡片及其下级的文字和顺序，包括折叠的下级。结果以选中卡片为锚点重排，可用**撤销整理**恢复。
- 圈住整张卡片后，提问按钮旁会出现拖动把手。拖把手可以移动选中的卡片，点把手可以进入 **移动** 模式。移动模式支持 Shift 点选增减卡片，拖任一选中卡成组移动。拖动卡片时按 Esc 可取消。
- **连线** 模式下，点选父卡，按住 **Shift** 向子卡拖动并松开。箭头指向子卡，拖到卡片上会高亮。也可依次点选父卡和子卡。点选已有连线后，可用 **删除连线** 解除关系。操作在浏览器本地保存。
- 整理后的父节点可以**展开下级**或**收起下级**，分别控制整条分支的显示。卡片正文可以单独折叠，刷新会保留分支状态。
- 选中卡片后，可以发送「用几张说明卡讲解这一段」。白板会在选区旁生成回答总览和 2 至 6 张说明卡，每张说明卡可以继续追问。选中已有批注并要求「把这段回答拆成几张说明卡」时，原卡会成为总览，原文可从**查看原回答**打开。
- 选中一个模块后，可在原有提问框发送「把这个模块拆成任务，列出依赖和验收标准」。任务会挂在所选模块下，也可继续选中任务向下拆解。每次拆解最多生成六个下级，支持整批撤销。前置依赖记录在任务卡中。
- 右侧 **更多工具 → 项目设计模板** 可以把同一张白板替换成项目总览、模块和细项。替换前会保存本机备份，可以通过 **撤销上次白板替换** 恢复。
- 首页的 **独立白板** 可打开手写板，**示例与手册** 可打开原白板、项目定义与交付或**代码仓库详解手册**。在独立白板和示例里也可用顶部 **切换白板**。手册沿实际入口、浏览器状态、模型执行与验证路径逐层展开。选中章节提问时会附上对应源码文件名。
- 新建白板时可填写本机**项目目录**，也可以从顶部 **管理 → 项目目录** 随时切换。每张白板单独保存目录。Codex 和 ZCode 可以只读分析绑定目录里的源码，留空使用白板项目目录。API 直连使用白板提交的内容和附件。
- 新建空白板后点 **初始化工程介绍**。Codex 或 ZCode 会先看目录和项目说明，再核对实际入口、关键模块和测试，生成总览、章节和可展开细节。初始化也会从本地项目里读取最多两张源码卡，点击卡片的 **展开** 可以查看片段。生成后可通过 **撤销整理** 回到空板。
- 选中一张卡后点 **重新生成分支**，可以在弹窗里写重写意见。范围包含当前卡及全部下级，包括收起的卡片。重写保留原有父子关系，可通过 **撤销整理** 恢复。
- 删除叶节点，或把父卡和全部下级一起选中删除，浏览器会直接更新卡片和连线。正在回答其他分支时，也可以删除与本轮无关的卡片。
- [源码架构手册（Codex）](http://127.0.0.1:8791/?board=repo-atlas) 是独立的源码审阅样板。先读「命中、执行、落板、维护」，再展开各章的步骤、源码依据和可复现问题。两张代码手册都可使用仓库索引。
- [白板功能示例](http://127.0.0.1:8791/?board=project-workbench&view=canvas) 按能力展开需求、实现和用例。选中需求后可让 AI 生成下级草稿，提问会带上该需求和关联用例。点「编辑卡片」可手动修改文字，或把生成的草稿标为需求或用例。已验证用例改动后回到待验证。

## 本机项目入口

初始化、查找本机工程和维护项目清单可使用 [whiteboard-local-setup 技能](.agents/skills/whiteboard-local-setup/SKILL.md)。

[首页](http://127.0.0.1:8791/) 展示本机的顶层项目。点「添加项目」填写名称和本机已有目录，保存后打开项目画布。同一目录再次添加时打开原项目。父项目内的「子项目」显示下一层卡片，页面顶部的路径导航可返回上一级。搜索也可以匹配子项目。

每张项目卡片显示简介和目录。「打开项目」直接进入项目画布。首次进入空画布，可点「写第一张卡片」建立主干，或使用 Codex/ZCode 初始化工程介绍。项目图展示所属项目的卡片与分支，AI 动作展示项目记录。点「关闭项目」回到首页。已保存的卡片和目录在重新打开时恢复，未发送或未保存的草稿会在离开前提示。Windows 上可点「打开文件夹」在资源管理器查看目录。

项目的本机动作快照放在清单旁的 `workbench-activity/<项目编号>.json`，文件内的 `projectId` 须与项目链接中的 `project` 一致。也可继续使用带同一字段的 `workbench-activity.local.json`。快照可提供项目状态、项目卡片、关联动作、来源和指导选项。没有快照的项目仍可打开独立画布与项目图，AI 动作页显示空状态。

已有项目介绍时，可以在快照中用 `initialBoard` 提供 `title`、`summary`、`items` 和 `collapsedBranches`。介绍应用于空画布，包括曾经打开并保存过的空板。用卡片的 `parentId` 表示层级，`sources` 填相对于绑定目录的源码路径。白板加载并保存介绍后，可继续编辑和展开，已有卡片与讨论保留。

本机项目快照的 `cardRequirements` 可为已有卡片关联需求。每项用 `cardId` 关联画布卡片，提供 `requirementId`、`title`、`need`、`method`、`validation`（每项为 `id`、`title`、`condition`）及已上传的 `attachment` 引用。白板上查看需求、实现和验收要点，详细说明可从附件打开。选中该卡继续提问时会携带关联说明和附件。

方法较长时，可选填 `methodDetails`，每段填写 `title` 和 `description`。卡片正文中的「实现细节」可展开查看这些段落。对照图或实验记录可用 `evidenceAttachments` 挂在同一需求下，最多四项。

项目资料保存在当前用户主目录下的 `.circle-ask-whiteboard/projects.local.json`，也可用环境变量 `WHITEBOARD_PROJECTS_FILE` 指定清单。清单使用 UTF-8 JSON 数组。每个项目包含 `name`（名称）、`description`（简介）、`category`（类别）和 `path`（本机绝对目录路径）。可用 `aliases` 补充常用叫法、缩写或用途短语。每个项目归入最近的已登记上级目录，编辑清单后刷新总览即可更新。

项目已有独立的本机白板服务时，可在本机清单为该项目设置 `boardUrl`，填写包含本机地址、端口和 `?board=…` 的原白板链接。「打开项目」会访问该服务的原画布。卡片和编辑记录继续在原地址的浏览器存储中读取。

```json
[
  {
    "name": "示例项目",
    "description": "包含训练脚本和评估报告。",
    "category": "模型实验",
    "path": "D:\\项目\\示例项目",
    "aliases": ["训练评估", "核对模型指标"]
  }
]
```

## 手册的仓库源码索引

在手册侧栏打开 **更多工具 → 仓库源码索引**，点击 **扫描当前仓库**。选中章节可查看索引收录的关联文件，章节里提到且已收录的符号可以直接点开。也可以输入准确的函数名，使用 `文件名#函数名` 区分不同文件中的同名符号。结果列出声明位置、直接调用者和被调用项。

这个功能使用单独安装的 GitNexus 1.6.12，要求 Node.js 22.18+ 或 24.11+。Windows 启动服务前可运行以下命令，服务会自动识别此目录。其他安装位置可以在启动前将 `WHITEBOARD_GITNEXUS_CLI` 指向 GitNexus CLI 入口的绝对路径。

```powershell
$repoIndexHome = Join-Path $env:LOCALAPPDATA 'CircleAskWhiteboard\tools\gitnexus\1.6.12'
npm install --prefix $repoIndexHome gitnexus@1.6.12 --no-audit --no-fund
```

服务在临时副本上以 `--index-only` 建立静态索引，覆盖本项目允许读取的实现文件。本机首轮扫描约 74 秒，服务运行期间会复用相同源码快照的结果。快照变化后需重新扫描。查询只展示能从源码静态解析的直接调用，浏览器与 Python 之间的 HTTP 跳转需要结合手册和源码。索引与查找在本机完成，独立于白板内容和模型连接。GitNexus 采用 PolyForm Noncommercial 1.0.0 许可证，单独安装使用。[GitNexus CLI 文档](https://github.com/abhigyanpatwari/GitNexus/blob/main/docs/cli-reference.md) · [许可证](https://github.com/abhigyanpatwari/GitNexus/blob/main/LICENSE)

## 本地数据与执行范围

白板、项目记忆和服务选择保存在浏览器的本地存储里。附件文件保存在用户主目录的 `.circle-ask-whiteboard/attachments`，可用环境变量 `WHITEBOARD_ATTACHMENTS_DIR` 指定其他本机目录。Python 服务只监听本机地址。智能体读取白板传入的选区、附件及相关上下文，整理结果由本地服务校验后再交给页面应用。

ZCode 请求、带附件的 Codex 请求和所有 Codex 改码请求在临时目录内处理原型源码和附件。源码编辑成功后，服务检查提交状态，只将允许编辑的前端文件改动应用回项目。停止成功会保留已保存的回答和白板状态。

Codex 或 ZCode 运行时，右侧 **执行过程** 会实时显示工具步骤、文件路径和结果。展开步骤可查看服务提供的短源码片段或已应用的改动片段。本轮记录保留在当前页面。

操作判断、解释分支、任务拆分、整理或重写分支、整板整理、初始化和孤立卡归位都使用结构校验。白板能识别说明文字中唯一完整的 JSON。若 ZCode 的结果仍未通过校验，会在同一会话内尝试修正一次。失败时可在批注或 **执行过程** 查看具体原因和一段脱敏返回片段。

## API 直连

在连接设置选择 API 直连，填写模型 ID、兼容 OpenAI Chat Completions 的基础地址（例如 https://api.openai.com/v1）和 Key。Key 仅在当前页面内存中使用，不写入浏览器存储或服务器文件，刷新即清除。接口地址也不持久化。发送后所选上下文和附件将交给指定接口。

支持问答、白板整理、PNG/JPEG/WebP/GIF 图片和 UTF-8 文本；模型须支持对应输入。图片和文本合计上限 20 MiB，每个文本附件 120 KB。结构化整理仍由本机校验后应用。该路线不执行任意命令、不读取项目文件、不修改代码；此类任务继续选择 Codex/ZCode。只允许 HTTPS 接口或本机 HTTP 服务，禁止自动跳转以避免 Key 泄漏。不需要安装额外技能或沙箱。

普通提问提交选区、相关分支和项目规则。可在侧栏 **更多工具 → 项目规则** 编辑目标、约束和已确认决定。整理提交所需节点，API 可以调用白板工具更新草稿。**更多工具 → 请求详情** 可查看本轮提示词和白板上下文。
